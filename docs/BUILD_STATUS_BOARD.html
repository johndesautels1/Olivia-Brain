⚠ The one thing to understand first — this project pivoted

There are two build plans living in the same repo. The original BATTLE_PLAN.md describes a relocation-intelligence "brain" (186 items, 9-model cascade, personas, memory). On 2026-05-02 the work pivoted: Olivia Brain became the canonical home for porting London Tech Map's (LTM) best technology — Studio Olivia, the valuation engine, the Quantara founder-intake, and Deal Protection — targeting a June 2026 demo. That newer plan lives in docs/BUILD_SEQUENCE.md and is organized as Tracks A–O.

The docs had drifted apart — OLIVIA_BUILD_STATE.md said 65%, BATTLE_PLAN.md said 85–88% (and contradicted itself), and the Track tables in BUILD_SEQUENCE.md were never re-checked even though the work shipped. That drift is now fixed at the source: build status is generated from the file system into docs/BUILD_TRUTH.md by npm run build:truth and enforced by a CI guard, so the numbers can't silently rot again. This board is a visual snapshot of that generated truth.

The architecture — hub & 6 spokes

1 / 6 docked

Olivia is the hub: a grand-master agentic super-agent with a token-authed gateway (src/lib/gateway) and a Universal Knowledge Protocol bridge (src/lib/bridge) that docks into six spoke apps. She's the brain, not the warehouse — each spoke stays the system of record for its own domain. A spoke counts as docked when a bridge provider exists for it; the rest are blocked by design until each app is live to expose its provider interface. This is exactly why the codebase looks broader than any single plan: the hub absorbs each spoke's best tech one at a time (London Tech Map first).
